# Publish and commit to GitHub

## Steps

1. **Commit to GitHub** — stage and commit any project changes that are not yet
   committed, with a message describing the invite-link fix and recent
   adjustments, then push to the connected GitHub repository.
2. **Publish** — request a publish of the current version (includes the invite
   sign-up fix, admin Newsletter page, homepage quote card, 8px button radius,
   and all other pending changes). Return the live URL.

## Notes

- Security check passed: no critical findings (one info-level note about
  public read access to site settings, which is intentional — the site reads
  its own settings publicly).
- Publish only makes the request; deployment typically takes about a minute.
