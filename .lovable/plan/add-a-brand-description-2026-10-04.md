# Add a brand description

## Changes
- Add a Brand description field in Account → Directory, limited to 160 characters with a live remaining count.
- Save it to the brand page and refresh the account view after saving.
- Use the same 160-character limit in the Share step and Admin brand editor.
- Keep displaying the description in the public brand page header and its page metadata.

## Validation
- Check saving, the character limit, and the public brand header on desktop and mobile.
